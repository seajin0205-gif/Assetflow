Case 01 · Dashboard Chart

복잡한 투자 데이터를 빠르게 이해하도록 점진적 정보 노출 적용

User Problem

수익·기간·상세 수치가 동시에 보이면 첫 화면에서 핵심을 읽기 어렵고, 모바일에서는 차트 탐색 부담이 큽니다.

Interaction Decision

초기에는 핵심 지표만 노출하고, 기간 선택 시 차트 데이터를 동기화해 탐색 부담을 줄였습니다.

Expected Outcome

첫 화면은 YTD 한 숫자로 요약되고, 관심 시점의 정확한 수치는 필요할 때만 확인합니다.

Case 02 · Trade Order

주문 불확실성을 줄이기 위해 검증-피드백 루프를 설계

User Problem

주문 후 접수 여부를 알기 어렵고, 입력 오류 시 어디를 고쳐야 하는지 즉시 파악하기 힘듭니다.

Interaction Decision

제출 전 검증을 단계화하고, 실패·성공을 각각 다른 토스트로 즉시 전달해 불확실성을 줄였습니다.

Expected Outcome

오류는 원인 메시지로 바로 복구하고, 성공 시 종목·수량·금액을 한눈에 확인합니다.

01
Input — 매수·매도와 수량 입력

거래 방향과 수량을 먼저 정하고, 미입력 시 CTA를 비활성화해 실수 클릭을 줄입니다.

02
Validate — 3단 검증 후 즉각 피드백

수량·보유량·지정가를 순서대로 검증하고, 실패 시 짧은 에러 토스트로 원인을 알립니다.

03

성공 시 종목·수량·예상 금액을 한 토스트에 정리해 접수 결과를 명확히 전달합니다.

Case 03 · Mood Tracker

감정 데이터를 리스크 분석과 연결하는 상태 동기화 인터랙션

User Problem

투자 결정 당시의 시장 심리를 기록할 방법이 없어, 이후 리스크 차트에서 맥락이 사라집니다.

Interaction Decision

5단계 무드 선택에 즉각적인 선택 피드백을 주고, 리스크 차트 마커와 UI 상태를 동기화했습니다.

Expected Outcome

한 번의 탭으로 감정이 기록되고, 차트에서 당시 심리를 역추적할 수 있습니다.
